
## Assignment Tracker

https://a3-sofiamccarty.onrender.com/

My project is an assignment tracker. You first log into the application, and it will show the form with all of your previous submissions. 
You fill out the form with the assignment type and grade, and you have the ability to delete or modify your previous entries.
Some challenges I face in this application were getting all of the front-end connected to the database, and being able to redirect from the login page to the main page.
I used cookies to authenticate since it seemed like the easiest to implement. 
I used the bootstrap framework since I've heard about it before and wanted to see how it worked.
